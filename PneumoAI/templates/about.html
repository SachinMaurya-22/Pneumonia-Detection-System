About PneumoAI

An educational Python and deep-learning project that demonstrates image classification using chest X-ray images.

Project Objective

To demonstrate how a trained machine-learning model can process an image and return a classification output through a web application.

Deep Learning Model

A compatible trained image-classification model is loaded by the Python backend. Its architecture, training data and performance should be documented in the project report.

Application Workflow

  1. User selects a chest X-ray image.
  2. Server validates the uploaded file.
  3. Image preprocessing matches model requirements.
  4. The model generates a classification output.
  5. The application displays the result.

Technology Stack

Python Flask TensorFlow / Keras HTML5 CSS3 JavaScript Bootstrap
Scope and Limitations

PneumoAI is an educational prototype, not a clinically validated diagnostic system. Performance depends on the training data, preprocessing, model calibration and external validation. Predictions must not replace professional medical assessment.
